# Список доработок для полноценного VPN-бота

Кроме самой выдачи VLESS/Xray-конфигов, проекту нужны следующие улучшения, чтобы стать production-ready Telegram VPN-магазином.

## 1. Профиль и UX (уже частично добавлено)

- [x] Кнопка **«Профиль»** с балансом и активной подпиской.
- [x] Пробный период ограничен **1 устройством**.
- [ ] История операций: пополнения, покупки, продления, реферальные начисления — отдельная кнопка «История».
- [ ] Редактирование профиля: смена языка (RU/EN), уведомления on/off.
- [ ] Приветственное сообщение с картинкой/видео инструкцией по подключению.
- [ ] Inline-подсказки и валидация вводимых данных (user_id, сумма, IP).
- [ ] Раздел FAQ / «Как подключиться» с мини-инструкциями для iOS/Android/Windows.

## 2. Тарифы и подписки

- [ ] Возможность админу менять цены и названия тарифов прямо в `/vpnadmin` (шагами, а не JSON).
- [ ] Автопродление: по истечении срока списывать с баланса и продлевать подписку, если хватает средств.
- [ ] Уведомления за 24ч / 1ч / по факту истечения подписки.
- [ ] Промокоды и скидки (процент/фиксированная сумма) с лимитом активаций и сроком действия.
- [ ] Партнёрские/подарочные подписки: генерация кода активации.
- [ ] Возврат средств за неиспользованный период (админская кнопка).
- [ ] Заморозка подписки на N дней (например, при отпуске) — продление срока заморозки.

## 3. Реферальная система

- [x] 2 уровня рефералов (10% / 5%).
- [ ] Промежуточный вывод реферального баланса (заявка на выплату).
- [ ] Бонус за N активных рефералов (например, +100₽ или +1 мес. подписки).
- [ ] Реферальные промокоды `?start=promo_abc`, привязанные к партнёру, а не только `ref_`.
- [ ] Лидерборд топ-рефереров и статистика конверсии.

## 4. Платежи

- [x] Crypto Bot (USDT/TON) — реальная интеграция.
- [x] Telegram Stars — реальная интеграция.
- [ ] **СБП / банковские карты** через провайдера (ЮKassa, CloudPayments, Robokassa, Lava и т.п.).
- [ ] Ручное подтверждение платежа админом (для переводов по реквизитам).
- [ ] Мультивалютность: USD/EUR/USDT/TON/RUB отображение баланса.
- [ ] Минимальная и максимальная сумма пополнения.
- [ ] Автоматический курс конвертации для Crypto Bot (USDT/TON ↔ RUB).

## 5. Устройства и безопасность

- [x] Автоматическая привязка устройства по первому подключению (IP + User-Agent), без ручного ввода IP.
- [x] Ограничение скорости/трафика, блокировка по подозрительной активности.
- [x] Anti-abuse: запрет шаринга — проверка одновременных подключений с разных IP.
- [x] Возможность пользователю самостоятельно отвязать устройство раз в N дней.
- [x] Логирование попыток подключения и уведомления админу о подозрительных действиях.

## 6. Админ-панель Cardinal

- [x] Управление токенами, каналом, поддержкой.
- [x] Просмотр пользователей, подписок, источников.
- [x] Поиск пользователя по @username / ID / номеру подписки.
- [x] Полная информация о пользователе: баланс, подписки, устройства, рефералы, источник, история платежей.
- [x] Bulk-операции: массовая рассылка, массовое продление, массовое начисление баланса.
- [x] Экспорт данных в CSV/Excel.
- [x] Настройка уведомлений админу: новый пользователь, новый платёж, истекающая подписка, жалоба.
- [x] Режим технических работ: бот отвечает «на обслуживании».

## 7. Маркетинг и аналитика

- [x] Подсчёт пользователей по источникам `/start`.
- [ ] UTM-статистика и воронка: источник → регистрация → пробный → платёж.
- [ ] Графики выручки, ретеншена, активных подписок (можно через Excel-экспорт или веб-панель).
- [ ] Интеграция с рекламными кабинетами / постбеки.

## 8. Связь с пользователями

- [ ] Тикет-система: пользователь пишет вопрос → админ отвечает через бота (анонимная пересылка).
- [ ] Массовая рассылка с фильтрами (всем / с активной подпиской / с истекающей / по источнику).
- [ ] Шаблоны сообщений, редактируемые админом.

## 9. Интеграции и инфраструктура

- [ ] Подключение к реальному Xray/3x-ui API для автовыдачи и отзыва ключей.
- [ ] Поддержка нескольких серверов/локаций (EU/RU/US/Asia) с выбором при покупке.
- [ ] Балансировка нагрузки и авто-переключение при падении сервера.
- [ ] Backup данных в облако / Telegram-канал (ежедневные дампы JSON).
- [ ] Docker-контейнер и systemd-unit для user-бота.
- [ ] Тесты: unit + интеграционные на mock API Telegram/Crypto Bot.

## 10. Юридика и надёжность

- [ ] Пользовательское соглашение и политика конфиденциальности (ссылка в `/start`).
- [ ] GDPR/CCPA: команда удаления всех данных пользователя.
- [ ] Логирование ошибок в отдельный файл/сервис (Sentry-совместимый формат).
- [ ] Rate limiting на пополнение и покупку, защита от спама.
